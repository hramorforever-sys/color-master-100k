# Color Master 100K licensing

All artwork shipped in this repository is original and created for this project. The project license is included in the repository root as `LICENSE`.

The app is designed to support a library of illustrations, but the current build intentionally ships with 100 original illustrations only. It does not rely on third-party copyrighted coloring pages without due rights.
